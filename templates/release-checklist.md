# Release review

- [ ] Scope and user outcome match the reviewed diff.
- [ ] Required checks executed; failures/skips are explained without weakened assertions.
- [ ] Data migration is compatible with old/new code; restoration has been exercised.
- [ ] Authorization, secrets, retention, and dependency changes were reviewed.
- [ ] Version, consumer migration notes, artifact digest, and ownership are recorded.
- [ ] Rollout stages, success metrics, abort threshold, and rollback/forward repair are explicit.
- [ ] Human release approval refers to the exact artifact.
- [ ] Post-release functional check and observation owner are assigned.
