# Reporting security issues

Do not put secrets, personal data, or exploitable details into a public issue.
Use GitHub private vulnerability reporting if enabled for this repository. If it is
unavailable, ask the maintainer for a private reporting channel without disclosing
the sensitive details. A channel has not been provisioned by this local build.

The local MCP server exposes public content read-only. Remote hosting requires a
separate authentication, rate-limit, privacy, and deployment review. Static hosting
does not provide server-side access control. See the security guide for adoption.
