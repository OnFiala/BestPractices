# Quellen und Werkzeuge

Dieses Register ist eine Auswahl, keine Pflicht zur Installation aller Werkzeuge. Projektgrenzen bestimmen die Wahl; vor Übernahme einen repräsentativen Ablauf prüfen. Kandidaten sind hier weder installiert noch getestet, außer bei used-here. MCP und Dokumentationsbau sind lokale Fähigkeiten; Workflows brauchen GitHub-Aktivierung. Quellenstatus beschreibt das gelesene Dokument, nicht alle veröffentlichten Versionen. Installierte Version und API prüfen. Hashes erkennen Änderungen; Menschen bewerten Bedeutung, Lizenz und Eignung. Produktnamen bleiben für eindeutige Identifikation unverändert. Vor Freigabe von Diensten und Zugangsdaten Integrations- und Hostingleitfäden lesen. Jedes Werkzeug bringt Wartung, Wiederherstellung und Wissensbedarf mit. Eine größere Werkzeugzahl bedeutet keine bessere Architektur. Die Tabelle ist regelmäßig anhand echter Projekterfahrung zu überprüfen.
